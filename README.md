MEDUSA OS is a Yocto minimalist Linux-based operating system image for the qemuarm64 architecture.

What it includes:
* Terminal optimized for the ARM64 environment.
* Integrated AI Chatbot, based on the Gemini 3.5 Flash model.
* System Info & Benchmarking for performance monitoring and testing system capabilities.

MEDUSA OS — implementation architecture
* 	• 	Kernel: QEMU ARM64 / aarch64, used for system development and testing.
* 	• 	GUI: native C++ + Qt 6 application, built with CMake.
* 	• 	Display server / compositor: Weston, based on the Wayland protocol.
* 	• 	Build & integration: Yocto Project, generating the complete system image.
* 	• 	Target: ARM64 (aarch64).
